# HK & Macau vlog guide

Phone-first trip guide for 28 Nov – 3 Dec 2026, served by GitHub Pages from `index.html`.

- Edit content in `src/data.js`, layout and behaviour in `src/app.html`.
- Rebuild with `python3 src/build.py` (inlines the data and Leaflet into `index.html`). Each build stamps its Hong Kong date and time, shown as the version next to the refresh button.
- Design mockups: `mockups/index.html`.
